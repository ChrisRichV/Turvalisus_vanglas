# Turvalisus vanglas

Õppeleht Sisekaitseakadeemia kursuse teemade kordamiseks tundide kaupa.

- **Tunnid → teemad**: iga teema 5 osas (mis see on, õiguslik alus, piiramine, vanglas, tüüpviga eksamil), skeem, tunni küsimuse vastus ja harjutused.
- **Klikitavad seaduseviited**: `PS § 18`, `EIÕK art 8` jne avavad sätte täpse teksti (Riigi Teataja / EUR-Lex / ÜRO, muutmata).
- **Kordamine**: tunni kordamisküsimused vastustega ja segatud harjutused (faktid + kaasused).
- **Teata veast**: iga teema lõpus saab saata parandusettepaneku.

Tehniline kirjeldus ja uue tunni lisamine: [README-projekt.md](README-projekt.md).

Kohapeal vaatamiseks: `python3 -m http.server` ja ava <http://localhost:8000>.

Selgitused on õppimiseks ega asenda ametlikku teksti. Seadused seisuga 10.11.2026.
